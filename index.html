📖 Breve História da Linguagem C

A linguagem C foi criada por Dennis Ritchie nos laboratórios Bell (AT&T) no início dos anos 1970, com o objetivo de implementar o sistema operacional UNIX. Tornou-se amplamente popular graças à sua eficiência, portabilidade entre plataformas e controle de baixo nível sobre memória e hardware.

Hoje, C é usada em kernels de sistemas operacionais, compiladores, firmwares, drivers e bibliotecas que formam a base de toda a computação moderna. Dominar C significa entender como os computadores realmente funcionam.

▶ Onde o Programa Começa

Todo programa em C começa pela função main(). O sistema operacional chama essa função e a partir daí você controla o fluxo de execução.

Cada instrução termina com ponto e vírgula (;). Esquecer o ponto e vírgula causa erro de compilação.

// Programa mais simples em C
#include <stdio.h>

int main(void) {
    printf("Olá, mundo!\n");
    return 0;
}
Para compilar e executar: gcc hello.c -o hello e depois ./hello. No Windows, use o executável hello.exe.

📦 Incluindo Bibliotecas

Use #include <nome> para adicionar dependências de bibliotecas padrão. Esse comando é processado antes da compilação pelo pré-processador.

#include <stdio.h>    // printf, scanf, fgets...
#include <math.h>     // sqrt, pow, sin, cos...
#include <string.h>   // strlen, strcpy, strcat...
#include <stdlib.h>   // malloc, free, rand...

#include <stdio.h>
#include <math.h>

int main(void) {
    double raio = 5.0;
    double area = M_PI * pow(raio, 2);

    printf("sqrt(16) = %.2f\n", sqrt(16.0));
    printf("Área (r=5) = %.4f\n", area);
    printf("sin(π/2) = %.2f\n", sin(M_PI / 2));

    return 0;
}
Ao compilar com gcc, adicione a flag -lm para linkar a biblioteca matemática:
gcc programa.c -o programa -lm

🔒 Definindo Constantes

Constantes podem ser definidas de duas formas: macros via #define ou variáveis imutáveis com const. Cada abordagem tem suas vantagens.

#define
Substituição de texto pelo pré-processador. Sem tipo, sem verificação de erros.
const
Constante com tipo. Verificada pelo compilador. Preferível na maioria dos casos.
#include <stdio.h>
#include <math.h>

// Macro — sem tipo (pré-processador substitui o texto)
#define PI_MACRO 3.141592653589793

int main(void) {
    double r = 5.0;

    // Usando macro
    printf("Área (macro) = %.6f\n", PI_MACRO * r * r);

    // Usando const — recomendado quando se quer tipagem
    const double PI = 3.141592653589793;
    printf("Área (const) = %.6f\n", PI * pow(r, 2));

    // Constante inteira com enum
    enum { MAX_USERS = 100 };

    return 0;
}
Portabilidade: M_PI não faz parte do padrão ISO C. Para portabilidade máxima, use const double PI = acos(-1.0); ou defina manualmente.

🧠 Exercício

Qual é o ponto de entrada de um programa em C? Q1
Em C, a função main() é sempre o ponto de entrada. O sistema operacional a chama ao iniciar o programa. Use return 0; para indicar que o programa terminou com sucesso.
