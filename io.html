Entrada e Saída
em C

A biblioteca stdio.h fornece todas as ferramentas para comunicação com o usuário: printf, scanf, fgets e muito mais.

📤printf — Saída Formatada

printf escreve texto formatado na saída padrão (stdout). Usa especificadores de formato para converter tipos em texto.

EspecificadorTipoExemplo de uso
%d / %iintprintf("%d", 10);
%uunsigned intprintf("%u", 300u);
%ccharprintf("%c", 'A');
%ffloat / doubleprintf("%.2f", 3.1415);
%enotação científicaprintf("%e", 0.000123);
%sstring (char*)printf("%s", nome);
%pponteiroprintf("%p", &var);
%%literal %printf("100%%");

Exemplos Práticos

#include <stdio.h>

int main(void) {
    // Formatação de inteiros
    printf("%d\n", 42);           // 42
    printf("%6d\n", 42);          // "    42"
    printf("%-6d|\n", 42);         // "42    |"
    printf("%06d\n", 42);          // "000042"

    // Formatação de floats
    printf("%.2f\n", 3.14159);     // 3.14
    printf("%8.3f\n", 3.14159);    // "   3.142"
    printf("%e\n", 0.000123);      // 1.230000e-04

    // Strings
    printf("%-10s|\n", "Olá");     // "Olá       |"

    return 0;
}

📥scanf — Leitura da Entrada

scanf lê dados da entrada padrão (stdin) convertendo texto digitado pelo usuário para variáveis do programa.

Regra de ouro: Sempre use & antes do nome da variável (exceto arrays). Ex.: scanf("%d", &n) — sem o & causa comportamento indefinido. 
#include <stdio.h>

int main(void) {
    int    n;
    float  f;
    double d;
    char   ch;
    char   nome[50];

    scanf("%d", &n);         // lê int
    scanf("%f", &f);         // lê float
    scanf("%lf", &d);        // lê double (atenção: %lf para scanf)
    scanf(" %c", &ch);       // lê char (espaço ignora whitespace)
    scanf("%49s", nome);     // lê string (sem &!)

    printf("n=%d f=%.1f d=%.1f ch=%c nome=%s\n",
           n, f, d, ch, nome);
    return 0;
}

📄fgets — Leitura Segura de Strings

fgets é a forma mais segura de ler strings com espaços, pois limita o número de caracteres lidos, evitando buffer overflow.

#include <stdio.h>
#include <string.h>

int main(void) {
    char nome[100];

    printf("Digite seu nome completo: ");
    fgets(nome, sizeof(nome), stdin);

    // fgets inclui o '\n' — remova se necessário:
    nome[strcspn(nome, "\n")] = '\0';

    printf("Olá, %s!\n", nome);
    return 0;
}
FunçãoUsoObservação
scanf("%s")Lê palavra únicaPara na whitespace — não lê frases
fgets(buf, n, stdin)Lê linha inteiraInclui \n, mais seguro
getchar()Lê um caractereRetorna int (verifica EOF)
puts(str)Imprime string + \nMais simples que printf para strings

🧠Exercício

Qual função é mais segura para ler strings com espaços? Q3
fgets é a opção correta: ela lê até n-1 caracteres, inclui espaços e previne buffer overflow. A função gets foi removida do padrão C11 por ser insegura.
