Lógica e
Operadores

Os operadores são as ferramentas para manipular dados: calcular, comparar e combinar condições lógicas.

➕Operadores Aritméticos

Realizam operações matemáticas entre valores numéricos.

OperadorOperaçãoExemploResultado
+Adição5 + 38
-Subtração5 - 32
*Multiplicação5 * 315
/Divisão15 / 43 (inteira!)
%Módulo (resto)17 % 52
++Incrementox++ ou ++xx + 1
--Decrementox-- ou --xx - 1
Divisão inteira: 15 / 4 == 3 (não 3.75). Para divisão com decimais, use 15.0 / 4 ou faça cast: (double)15 / 4. 
int a = 10, b = 3;
printf("%d + %d = %d\n", a, b, a + b);  // 13
printf("%d / %d = %d\n", a, b, a / b);  // 3 (inteira)
printf("%d %% %d = %d\n", a, b, a % b); // 1 (resto)
printf("%.2f\n", (double)a / b);         // 3.33

int x = 5;
printf("%d\n", x++); // imprime 5, depois x=6
printf("%d\n", ++x); // x=7, depois imprime 7

⚖️Operadores Relacionais

Comparam dois valores e retornam 1 (verdadeiro) ou 0 (falso). São usados em condições de if, while, etc.

OperadorSignificadoExemploResultado (a=5, b=3)
==Igual aa == b0 (falso)
!=Diferente dea != b1 (verdadeiro)
>Maior quea > b1
<Menor quea < b0
>=Maior ou iguala >= 51
<=Menor ou igualb <= 31
Erro clássico: Não confunda == (comparação) com = (atribuição). if (x = 5) sempre é verdadeiro!

🔀Operadores Lógicos

Combinam múltiplas expressões booleanas. Em C, qualquer valor diferente de 0 é considerado verdadeiro.

OperadorNomeExemploResultado
&&AND lógicoa > 0 && b < 10Verdadeiro se ambos forem verdadeiros
||OR lógicoa == 0 || b == 0Verdadeiro se ao menos um for verdadeiro
!NOT lógico!(a > 0)Inverte o resultado
 
int idade = 20, tem_carteira = 1;

if (idade >= 18 && tem_carteira) {
    printf("Pode dirigir\n");
}

int x = 0;
if (!x) {
    printf("x é zero (falso)\n");  // !0 = 1 (verdadeiro)
}

📝Operadores de Atribuição

Formas compactas de combinar operação e atribuição.

OperadorEquivalente aExemplo (x=10)
x += 5x = x + 5x → 15
x -= 3x = x - 3x → 7
x *= 2x = x * 2x → 20
x /= 4x = x / 4x → 2
x %= 3x = x % 3x → 1

🧠Exercício

Qual operador retorna verdadeiro somente se ambas as condições forem verdadeiras? Q4
O operador && (AND) retorna verdadeiro apenas quando ambas as expressões são verdadeiras. O || (OR) retorna verdadeiro se ao menos uma for verdadeira.
