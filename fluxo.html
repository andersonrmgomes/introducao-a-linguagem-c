Estruturas
de Controle

Controle o fluxo do seu programa com condicionais e laços: if/else, switch, for, while e do-while.

🔀if / else if / else

Executa blocos de código com base em condições. Se a condição for diferente de zero, o bloco é executado.

int nota = 75;

if (nota >= 90) {
    printf("A — Excelente\n");
} else if (nota >= 70) {
    printf("B — Bom\n");
} else if (nota >= 50) {
    printf("C — Regular\n");
} else {
    printf("D — Reprovado\n");
}

Operador Ternário

Forma compacta de um if/else de uma linha: condicao ? valor_se_true : valor_se_false

int idade = 20;
char *status = (idade >= 18) ? "maior" : "menor";
printf("%s de idade\n", status);  // "maior de idade"

int max = (a > b) ? a : b;  // maior entre a e b

🎚️switch

Compara uma expressão inteira ou char com constantes case. Use sempre break para evitar o fall-through (execução dos casos seguintes).

❌ Sem break (fall-through)
int dia = 2;
switch (dia) {
    case 1: printf("Seg\n");
    case 2: printf("Ter\n");
    case 3: printf("Qua\n");
}
// Saída: Ter Qua
// (executou case 2 e 3!)
✅ Com break (correto)
int dia = 2;
switch (dia) {
    case 1: printf("Seg\n"); break;
    case 2: printf("Ter\n"); break;
    case 3: printf("Qua\n"); break;
    default: printf("???\n");
}
// Saída: Ter

🔄Laços de Repetição

C oferece três estruturas de repetição, cada uma com um caso de uso ideal.

for — Repetição controlada

Ideal quando se sabe o número de iterações de antemão.

// Sintaxe: for (inicialização; condição; incremento)
for (int i = 0; i < 5; i++) {
    printf("%d ", i);  // 0 1 2 3 4
}

// Percorrendo array
int nums[] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    printf("nums[%d] = %d\n", i, nums[i]);
}

while — Repetição condicional

A condição é verificada antes de cada iteração. Se já for falsa no início, o bloco nunca executa.

int n = 1;
while (n <= 5) {
    printf("%d\n", n);
    n++;
}

// Ler até digitar 0
int val;
while (scanf("%d", &val) == 1 && val != 0) {
    printf("Lido: %d\n", val);
}

do-while — Executa ao menos uma vez

A condição é verificada depois da primeira execução.

int opcao;
do {
    printf("Menu: [1] Novo  [2] Sair\n");
    scanf("%d", &opcao);
} while (opcao != 2);
printf("Saindo...\n");

⛔break e continue

break — interrompe o laço
for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    printf("%d ", i);
}
// 0 1 2 3 4
continue — pula a iteração
for (int i = 0; i < 6; i++) {
    if (i % 2 == 0) continue;
    printf("%d ", i);
}
// 1 3 5 (pula pares)

🧠Exercício

Qual estrutura garante que o bloco execute ao menos uma vez? Q5
O do-while verifica a condição após executar o bloco, então o corpo sempre executa pelo menos uma vez. Útil para menus interativos e validação de entrada.
