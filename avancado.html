🎯Ponteiros

Um ponteiro é uma variável que armazena um endereço de memória. Com ponteiros você pode referenciar e modificar dados indiretamente — essencial para funções, arrays e alocação dinâmica.

& — address-of
Obtém o endereço de uma variável: &x retorna o endereço onde x está na memória.
* — dereference
Acessa o valor no endereço apontado: *px lê ou escreve no local onde px aponta.
#include <stdio.h>

int main(void) {
    int  x  = 42;
    int *px = &x;   // px aponta para x

    printf("x   = %d\n",  x);    // 42
    printf("&px  = %p\n", &x);   // endereço de x
    printf("px  = %p\n",  px);   // mesmo endereço
    printf("*px = %d\n", *px);   // 42 (valor em x)

    *px = 100;   // altera x indiretamente
    printf("x agora = %d\n", x);  // 100

    return 0;
}

Ponteiros em Funções

Passe ponteiros para permitir que uma função modifique variáveis do chamador:

// Troca dois valores via ponteiros
void troca(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int x = 10, y = 20;
    troca(&x, &y);
    printf("x=%d y=%d\n", x, y);  // x=20 y=10
    return 0;
}
Sempre inicialize ponteiros antes de usar. Um ponteiro não inicializado aponta para um endereço aleatório — desreferenciar causa segfault ou corrupção silenciosa de memória.

💾Alocação Dinâmica de Memória

Aloca memória em tempo de execução com malloc, calloc e realloc. Sempre libere com free.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;

    // malloc: aloca n ints sem inicializar
    int *v = (int *)malloc(n * sizeof(int));
    if (v == NULL) {
        fprintf(stderr, "Memória insuficiente\n");
        return 1;
    }

    for (int i = 0; i < n; i++) v[i] = (i + 1) * 10;
    for (int i = 0; i < n; i++) printf("%d ", v[i]);
    printf("\n");

    free(v);   // libera a memória!
    v = NULL;  // boa prática: evita dangling pointer
    return 0;
}
FunçãoUsoInicializa?
malloc(n)Aloca n bytesNão (lixo)
calloc(q, t)Aloca q×t bytesSim (zeros)
realloc(p, n)Redimensiona bloco—
free(p)Libera memória—

📁Acesso a Arquivos

C permite ler e escrever arquivos com as funções da stdio.h. O fluxo de trabalho é sempre: abrir → operar → fechar.

Escrevendo em arquivo

#include <stdio.h>

int main(void) {
    FILE *f = fopen("dados.txt", "w");
    if (f == NULL) {
        perror("Erro ao abrir arquivo");
        return 1;
    }

    fprintf(f, "Nome: João\n");
    fprintf(f, "Idade: %d\n", 25);

    fclose(f);
    printf("Arquivo salvo.\n");
    return 0;
}

Lendo arquivo linha por linha

FILE *f = fopen("dados.txt", "r");
if (f == NULL) { perror("erro"); return 1; }

char linha[256];
while (fgets(linha, sizeof(linha), f) != NULL) {
    printf("%s", linha);  // fgets já inclui '\n'
}
fclose(f);
ModoDescrição
"r"Leitura (arquivo deve existir)
"w"Escrita (cria ou sobrescreve)
"a"Append (adiciona ao final)
"r+"Leitura e escrita
"rb" / "wb"Modo binário
Boas práticas: Sempre verifique se fopen retornou NULL. Sempre feche arquivos com fclose. Use perror para mensagens de erro descritivas.
