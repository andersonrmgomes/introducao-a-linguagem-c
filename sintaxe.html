Sintaxe Básica
e Tipos de Dados

Os blocos fundamentais de qualquer programa em C: variáveis, tipos primitivos e como formatar entrada/saída.

🔢Tipos de Dados Primitivos

C oferece um conjunto compacto de tipos primitivos. O tamanho exato depende da plataforma, mas a ordem de precisão é sempre a mesma.

TipoDescriçãoTamanho típicoExemplo
charCaractere (inteiro de 8 bits)1 bytechar c = 'A';
intInteiro padrão4 bytesint n = 42;
shortInteiro curto2 bytesshort s = 100;
longInteiro longo4–8 byteslong l = 100000L;
floatPonto flutuante simples4 bytesfloat x = 3.14f;
doublePonto flutuante duplo8 bytesdouble d = 2.71828;
unsigned intInteiro sem sinal4 bytesunsigned int u = 300;
 
#include <stdio.h>

int main(void) {
    char   c = 'A';
    int    n = 42;
    float  f = 3.14f;
    double d = 2.71828;

    printf("char:   %c (%d)\n", c, c);
    printf("int:    %d\n", n);
    printf("float:  %.2f\n", f);
    printf("double: %.5f\n", d);

    return 0;
}

📤printf — Formatando Saída

printf converte valores em texto usando especificadores de formato que começam com %.

EspecificadorTipoExemploSaída
%dintprintf("%d", 42);42
%ccharprintf("%c", 'A');A
%ffloatprintf("%.2f", 3.14f);3.14
%lfdoubleprintf("%lf", 2.718);2.718000
%sstringprintf("%s", "Olá");Olá
%pponteiroprintf("%p", &x);0x7fff...
%xhexprintf("%x", 255);ff

Largura e Precisão

Controle o alinhamento e o número de casas decimais diretamente no especificador.

printf("%6d", 42);       // "    42" — largura mínima 6
printf("%-6d|", 42);     // "42    |" — alinhado à esquerda
printf("%.2f", 3.14159); // "3.14" — 2 casas decimais
printf("%8.3f", 3.14159);// "   3.142" — largura 8, 3 decimais
printf("%05d", 42);      // "00042" — zero-padding

📥scanf — Lendo Entrada

scanf lê dados da entrada padrão. Use & (operador de endereço) antes das variáveis, exceto para arrays/strings.

EspecificadorTipoUso
%dintscanf("%d", &n);
%ffloatscanf("%f", &x);
%lfdoublescanf("%lf", &d);
%ccharscanf(" %c", &c);
%sstringscanf("%s", nome);
 
#include <stdio.h>

int main(void) {
    int    idade;
    float  altura;
    char   nome[50];

    printf("Nome: ");
    scanf("%49s", nome);       // limite de 49 chars + '\0'

    printf("Idade: ");
    scanf("%d", &idade);

    printf("Altura: ");
    scanf("%f", &altura);

    printf("\n%s tem %d anos e %.2fm\n", nome, idade, altura);
    return 0;
}
Atenção: Ao ler strings com espaços, prefira fgets(nome, sizeof(nome), stdin); pois scanf("%s") para no primeiro espaço.

🧠Exercício

Qual especificador do printf imprime um int? Q2
Use %d para inteiros, %f para float/double e %s para strings. Para double em scanf, use %lf.
