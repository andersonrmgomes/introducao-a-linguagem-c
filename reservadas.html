Palavras
Reservadas

Identificadores que pertencem à linguagem C e não podem ser usados como nomes de variáveis, funções ou tipos definidos pelo programador.

📚Palavras Reservadas do C (C99/C11)

Estas palavras têm significado especial para o compilador. Usá-las como identificadores causa erro de compilação.

/* Tipos e modificadores */
char      short     int       long
float     double    void      _Bool
_Complex  _Imaginary
signed    unsigned

/* Controle de armazenamento */
auto      extern    static    register
const     volatile  restrict  inline
typedef

/* Estruturas e tipos compostos */
struct    union     enum

/* Controle de fluxo */
if        else      switch    case
default   for       while     do
break     continue  return    goto

/* Operadores e misc */
sizeof

/* C11 — novidades */
_Alignas  _Alignof  _Atomic   _Generic
_Noreturn _Static_assert      _Thread_local

🔍Referência por Categoria

Tipos de Dados

PalavraSignificado
charTipo inteiro de 8 bits / caractere
intTipo inteiro padrão
floatPonto flutuante de precisão simples
doublePonto flutuante de dupla precisão
voidAusência de tipo / sem retorno
structDeclara tipo agregado (registro)
unionTipo que compartilha memória entre membros
enumTipo de enumeração de constantes inteiras

Qualificadores e Modificadores

PalavraSignificado
constValor não pode ser modificado após inicialização
volatileValor pode mudar externamente (hardware, threads)
staticVariável com duração estática / função com escopo interno
externVariável/função definida em outro arquivo
registerSugere armazenamento em registrador (obsoleto)
signed / unsignedControla sinal do tipo inteiro
short / longControla tamanho do tipo inteiro
inlineSugere expansão inline da função (C99)
typedefCria alias para um tipo

Controle de Fluxo

PalavraUso
if / elseCondicional simples
switch / case / defaultDesvio múltiplo
forLaço com contador
whileLaço com condição pré-testada
doLaço com condição pós-testada (do-while)
breakInterrompe laço ou switch
continuePula para a próxima iteração
returnRetorna valor e encerra função
gotoDesvio incondicional (evite usar)
sizeofRetorna tamanho em bytes de um tipo/variável
Atenção: palavras como inline, restrict e as que começam com _ foram introduzidas em versões posteriores (C99/C11). Verifique o padrão alvo do seu compilador com a flag -std=c11.

🧠Exercício

Qual das opções abaixo é uma palavra reservada em C? Q8
for é uma palavra reservada usada para laços. main é apenas uma função convencional — pode ser reusada como identificador (embora seja má prática). loop não existe em C.
