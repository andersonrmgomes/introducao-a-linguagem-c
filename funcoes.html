Funções e
Modularização

Funções são os blocos de construção da modularidade em C — dividem problemas complexos em partes reutilizáveis e testáveis.

⚙️Anatomia de uma Função

Uma função em C tem quatro partes: tipo de retorno, nome, parâmetros e corpo.

// tipo_retorno  nome    (parâmetros)
int            soma    (int a, int b) {
    return a + b;   // retorna o resultado
}

int main(void) {
    int resultado = soma(3, 4);
    printf("3 + 4 = %d\n", resultado);  // 7
    return 0;
}

↩️Funções com Retorno

Calculam um valor e o devolvem ao chamador com return.

// Calcula a média de três notas
float media(float n1, float n2, float n3) {
    return (n1 + n2 + n3) / 3.0f;
}

// Retorna o maior entre dois inteiros
int maior(int a, int b) {
    return (a > b) ? a : b;
}

// Verifica se é par (retorna 1 ou 0)
int e_par(int n) {
    return n % 2 == 0;
}

int main(void) {
    printf("Média: %.2f\n", media(7.5f, 8.0f, 6.5f));  // 7.33
    printf("Maior: %d\n", maior(12, 7));               // 12
    printf("4 é par? %s\n", e_par(4) ? "sim" : "não"); // sim
    return 0;
}

🚫Funções void

Não retornam valor — apenas executam uma ação.

// Imprime uma saudação
void saudacao(char *nome) {
    printf("Olá, %s! Bem-vindo.\n", nome);
}

// Imprime uma linha separadora
void separador(int n) {
    for (int i = 0; i < n; i++) putchar('-');
    putchar('\n');
}

int main(void) {
    separador(30);
    saudacao("Alice");
    saudacao("Bob");
    separador(30);
    return 0;
}

📋Protótipos de Funções

Se uma função é usada antes de ser definida, declare um protótipo no início do arquivo. O protótipo informa ao compilador a assinatura da função.

#include <stdio.h>

// Protótipos (declarações antecipadas)
int   fatorial(int n);
float celsius_para_fahrenheit(float c);

int main(void) {
    printf("5! = %d\n", fatorial(5));
    printf("100°C = %.1f°F\n", celsius_para_fahrenheit(100));
    return 0;
}

// Definições (implementações)
int fatorial(int n) {
    if (n <= 1) return 1;
    return n * fatorial(n - 1);  // recursão!
}

float celsius_para_fahrenheit(float c) {
    return c * 9.0f / 5.0f + 32.0f;
}

🗃️Arrays (Vetores)

Arrays armazenam múltiplos elementos do mesmo tipo em posições contíguas na memória. O índice começa em 0.

#include <stdio.h>

int main(void) {
    // Declaração e inicialização
    int notas[5] = {85, 92, 78, 96, 88};

    // Percorrer e somar
    int soma = 0;
    for (int i = 0; i < 5; i++) {
        soma += notas[i];
        printf("notas[%d] = %d\n", i, notas[i]);
    }
    printf("Média: %.1f\n", (float)soma / 5);

    // String é um array de char terminado em '\0'
    char nome[] = "Linguagem C";
    printf("Nome: %s (%lu chars)\n", nome, sizeof(nome) - 1);

    return 0;
}
Acessar índice fora dos limites (ex.: notas[5] em array de 5 elementos) causa comportamento indefinido — pode corromper memória ou gerar segfault.

🧠Exercício

Qual é o índice do primeiro elemento de um array em C? Q6
Arrays em C começam no índice 0. Para um array de tamanho n, os índices válidos são 0 a n-1. Ex.: int v[5] → índices 0, 1, 2, 3, 4.
